# Configuraciones

Esta carpeta contiene las configuraciones utilizadas en la Infraestructura 2.

## Router Cisco R1

El archivo `R1-running-config.txt` contiene la configuración completa del router Cisco utilizado en el laboratorio, incluyendo:

- Configuración de interfaces.
- DHCP para la red de Usuarios.
- NAT y excepción de NAT para el tráfico VPN.
- Configuración IKE/IPsec.
- Crypto Map.
- ACL utilizadas para NAT y VPN.

> La clave precompartida (Pre-Shared Key) utilizada en la VPN se oculta en la documentación por seguridad.
